# 九学科领域契约与结构化校验（第 3 部分）

状态：前端契约与数据库迁移脚本已加入；尚未导入任何外部教材、题目、知识点或地区模板内容。  
日期：2026-09-02

## 本部分交付

- `assets/js/domain-schema.js`：九学科、七至九年级、五级难度、题目/试卷校验、有效作业判定、学情报告门槛和展示文本清洗。
- `server/migrations/002_learning_domain.sql`：教材版本、知识点节点/关系、结构化题目、地区卷型、工作流运行、报告运行、资料来源和图形产物的专用表。
- `workbench.html`：在旧业务脚本前加载领域契约，后续页面可通过 `window.FH_DOMAIN` 调用统一规则。

## 范围与别名

规范化学科为：语文、数学、英语、物理、化学、生物、历史、道德与法治、地理。  
兼容旧数据的别名：`foreign_language` → 英语，`政治`/`思想品德` → 道德与法治。旧别名只用于读取兼容，新增记录必须写入规范编码。

## 题目质量底线

每道题必须使用 `question.v1`，具备学段、年级、学科、题型、难度、知识点、前置知识、能力维度、题干、答案、解析、来源、生成记录、审核记录和可追溯信息。校验失败的题目只能停留在草稿或待修复状态，不能直接进入试卷或学生端。

难度 1—5 级和预计得分率区间已固化在契约中。难度 4—5 的判定要求来自知识结构、条件转化、建模、探究、分类讨论或多阶段论证，不能只用题目长度、计算量或晦涩表达冒充高难度。

## 学情报告门槛

`reportEligibility()` 先在所选报告周期内过滤正式提交、可计分、非草稿、非重复、未删除和未判无效的作业，再分别统计每个被选学科。每个选中学科少于 3 次时返回缺口，不调用 AI；只有所有选中学科达标后，才允许将确定性统计交给解释模型。

## 迁移边界

本部分只建表和校验器，不包含 seed。旧 `records` 不会自动搬入新表；迁移时必须由第 2 部分的审计清单逐条确认来源、所有者、引用关系和备份哈希，再以版本化记录迁移。真实用户、教师创建内容和学生作业默认保留。
