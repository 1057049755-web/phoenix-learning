# 本地重构交付与验收记录（第 9 部分）

日期：2026-09-02

## 本次完成

- 增加服务端报告接口：先从有效提交计算统计，再按每个所选学科至少三次的规则决定是否允许 AI 解读；不足时只落库门槛结果，不发起模型请求。
- 增加独立学习闭环表：作业、草稿与正式提交、教师反馈、错题、笔记、通知。旧版通用快照保留用于兼容，不删除真实业务数据。
- 增加公开资料入口：只接受公开 HTTPS 页面；检查 robots.txt、拒绝登录/付费/权限拦截页面、限制响应大小和超时，并记录解析方式、完整度、版权状态与失败原因。采集失败后可由教师手动补充有权使用的正文。
- 增加制图安全校验和受限矢量渲染器：允许的 11 类 Skill 统一检查 SVG 完整性、脚本/外部嵌入、元素 ID 唯一性、无障碍标题、文字说明和黑白打印安全性；结构化元素只由白名单渲染器生成，服务端不会执行模型生成的任意系统代码。
- 组卷、批改、报告和学生首页继续使用结构化工作流；教师评分后可确认发布，学生端只读取已发布反馈，并尝试加载独立学习闭环数据。
- 模型目录补充 MiniMax 开放平台、腾讯云 TokenHub 和 Perplexity API，共 20 个入口；模型名称、价格和可用状态仍由官方接口同步写入，页面只展示最近一次成功快照及官方价格入口。
- 教师资源页接入公开资料采集服务，支持公开 HTTPS 直接采集和有权内容手动补充，并保存来源元数据与失败原因。
- 修正模板目录的展示方式，不再把结构对象直接拼成原始 JSON 文本。

## 数据迁移与恢复

- `007_learning_loop_and_sources.sql` 增加学习闭环表和资料字段；`008_model_provider_directory_expansion.sql`、`009_model_provider_perplexity.sql` 增加模型平台目录。
- 旧模型目录仍保存在 `005` 创建的恢复表中；旧题目、教材正文、知识语料及真实用户业务记录没有被自动删除。
- 资料采集正文仅在教师明确提交并通过来源入口后保存；教材系统继续只保存目录、结构化知识和来源元数据。
