- **计划可执行化**：学习计划页自动把推荐知识点和错题拆成今日任务，完成状态写入 `plan_tasks`，打开知识点、反馈推荐和完成任务都会形成 `learning_events`。
- **本地多集合数据层**：在原有业务集合外增加 `profiles / knowledge / content_tags / goals / plan_tasks / learning_events / recommendation_feedback / review_schedule / data_dictionary`，全部可在本机 `server/data/` 或浏览器本地存储中运行。
- **网络接入准备**：工作台账号菜单和管理员「学校管理」均提供“网络接入”，可配置局域网 / 独立 API 地址与访问令牌，支持 `/api/ping` 健康检查；网络中断时按集合保留本机待同步快照，恢复后自动补传。
- **角色隔离不互通**：学生 / 教师 / 管理员各自登录各自的端，账号菜单不再有“切换角色”；删除演示直通参数，旧演示数据使用独立存储键，互不污染。

## 快速开始

- 直接双击 `index.html`：先在启动入口选择学生端、教师端或管理端；未配置独立地址时，会进入 `workbench.html` 的统一登录页并自动预选身份。管理员手机号 `13800000001`，密码 `admin123`（首次使用请及时在「账号菜单 → 修改密码」中更换）。
- 团队介绍与完整使用指南见 `team-index.html`；三端内部 URL 可在启动入口的「配置三端」中填写，地址只保存在当前浏览器。
- 管理员导入成员后，让学生 / 教师用手机号 + 初始密码（手机号后 6 位）登录，按提示完成首次激活。
- 想让网页、手机、平板在同一局域网共享本机数据：进入 `server/` 执行 `node server.js`，访问 `http://127.0.0.1:8080/`（详见 `server/README.md`）；无需上云。
- 顶栏可模拟弱网/离线；`预览截图/` 内附关键页面截图（含手机 / 平板 / 安卓端）。
- **iOS / iPadOS**：网页已提供 PWA 清单与 Apple 主屏幕元数据。通过 HTTPS 打开后，在 Safari 选择“添加到主屏幕”，即可使用独立窗口、图标与安全区适配的移动端界面；当前仓库未包含原生 iOS 工程，网页与安卓 WebView 共用同一套 UI 资源。

## AI 协作工作台

- 登录后，在任一业务目录顶部的“目录工具”点击“AI 助手”。系统会按学生、教师、管理员身份显示不同任务模板。
- 输入前先删除姓名、手机号、密码、API Key 等敏感信息。页面不会自动读取账号数据、当前页面、研究记录或外部链接。
- AI 结果先进入可编辑预览，可由用户明确选择复制、加入研究记录、转为行动清单或加入今日计划；不会自动写入业务数据。
- “行动清单 → AI 拆解”“研究记录 → 整理为证据链”“公告管理 → AI 起草 / 润色”使用同一模型配置，并保留完整手动回退。
- 模型输出属于辅助草稿，教学内容、数据结论、公告时间与发布范围都需要人工复核。

## 已实现的关键交互

- 命题：学科 / 年级（1-9）/ 学期 / 教材版本选择 → 章节树或知识点图谱勾选 → AI 生成（每题带参考答案、“从知识点讲起”的详解与完整思考/计算过程）→ 逐题编辑 / 替换 / 删除 / 标记已复核；右侧面板实时统计；命名后可真实导出。
- 题型体系：选择题 / 判断题 / 填空题 / 多选题 / 阅读题 / 解答题六类（借鉴 Moodle GIFT 与 H5P 的题型设计）；语文、英语的“全部题型”自动混入阅读题，数学不混入；单元测试卷与中考模拟卷模板内置判断、阅读大题。
- **全部实时生成、绝不重复**：题目 / 详解 / 学习计划 / 资料排版全部由 AI 实时生成，本地兜底题库已删除（未接入模型时明确提示先配置，不再静默填充示例题）。AI 返回按“题位一一对应”校验，整卷自动去重（题干归一化比较），重复或缺漏即报错重试，杜绝重复题。
- 所有答案不可省略：AI 返回题若缺少答案或出现“略”，会判为无效题并重试，直到全部题位给出完整答案、解题过程与五段式详解。
- 每题含「知识点讲解（不只讲答案）」：AI 生成时强制输出 kp 字段——先讲清本题知识点（概念/法则/方法），再给出至少一条外延（相关知识点、现实应用、变式方向或易混对比），题目卡片与导出答案区均单独展示。
- 数学制图：数学题按“题干参数”现生成图形——从题面解析出函数系数（如 `y = x²-4x+3` 直接画出该抛物线、标出顶点/零点/截距）、圆半径、长方形长宽、圆柱半径高、数轴上的点等；题目卡片、Word / PDF 导出的题目区与答案区都带图。统计图（饼图 / 条形图）用 Chart.js 渲染，几何图用纯 SVG；AI 出题要求返回 figure 字段并校验一致性，AI 没给图时系统也按题干自动补图，未配置 AI 同样出图。
- 两种组卷模式：
  - 自由组卷：题型 / 难度 / 数量，AI 按“题位规格”分块生成（每块 2-3 题，避免一次信息过多），返回后逐题校验题型、难度与字段完整性，缺漏自动重试并补全，保证数量与难度严格执行。
  - 整卷模板：按地区中考 / 期末 / 单元测试的真实题型与难度分布整卷生成（如厦门中考数学：选择 10×4 + 填空 6×4 + 解答 9 题共 150 分 / 120 分钟），逐大题分块生成并显示进度。
- 题目累积：多次生成会追加到同一试卷（右上可一键清空），题号自动重排。
- 导出：Word（.doc，Word/WPS 可直接打开）、PDF（市面卷 A4 打印预览）与 GIFT 文本题库（可导入 Moodle / 支持 GIFT 的平台）——含卷头（校名/标题/满分/时间）、班级姓名学号栏、注意事项、分题型题目与答题区、末页参考答案与详解（含解题过程）。
- 答案与试卷彻底分离：导出可选「教师版（题目 + 答案与详解）」或「学生版（纯试卷，不含任何答案）」，学生版末页附交卷说明。
- 考试时间与建议时长按公式自动计算（见下节），试卷面板实时显示并随导出联动。

## 阅读题 · 公有领域阅读库与网络检索

语文 / 英语新增「阅读题」题型，材料来源全部为**公有领域或开放许可**文本，题库内置 `corpus.js → reading`：

| 语言 | 材料示例 | 来源与许可 |
| --- | --- | --- |
| 语文 · 现代文 | 鲁迅《从百草园到三味书屋》《故乡》、朱自清《背影》《荷塘月色》、老舍《济南的冬天》、梁启超《少年中国说》、周作人《乌篷船》 | 已进入公有领域，可自由选用 |
| 语文 · 古诗文 | 《岳阳楼记》《桃花源记》《陋室铭》《观沧海》 | 公有领域 |
| 英语 | 伊索寓言（狐狸与葡萄、龟兔赛跑、狼来了、北风与太阳）、格林童话《小红帽》、Alice in Wonderland、A Christmas Carol、Tom Sawyer、The Gift of the Magi、Treasure Island | 公有领域经典节选 |

**工作流**：

- 自由组卷选「阅读题」后出现「联网检索公有领域文本」工具：调用维基文库（Wikimedia API，免 Key，CORS 开放）按关键词检索，选用后把原文注入 AI 出题上下文；检索失败或未选用时自动回退内置阅读库。
- 检索结果与正文会自动**筛选体裁与适合性**：体裁识别覆盖小说 / 散文 / 诗歌 / 古文（英文为小说 / 散文 / 诗歌），过滤消歧义页、导航页与正文缺失（过短）页面，不合格时提示改用内置语料库。
- 中文正文自动**繁体转简体**（内置常用字表 + 常见短语如“戴著→戴着”），古诗文保留原文并标注体裁。
- 阅读题结构固定为「**一段长文本在前，下面跟 2-3 个编号小题**」：passage 放完整材料（≥80 字，诗歌/古文保留原文），stem 只放编号小题；AI 若漏传材料或漏写小题，系统自动从公有领域库补齐并补标准小题模板。
- AI 出题样式参考中考 / 高考及模拟卷：语文（字词、内容理解、句子赏析、段落作用、主旨、开放性题），英语（细节理解、主旨大意、词义猜测、推理判断）。
- 若对原文做了节选或改编，AI 必须在材料文末标注「本文改编自《X》（来源），有删改」，题目卡片与导出试卷均保留该标注。

## 考试时间 / 建议时长公式

按“体量 + 难度”自动计算，公式在 `ai.js → estimatePaperTime()`：

```text
净答题秒数 = 120（卷面说明等固定开销）
          + Σ 每题（题型基础秒数 × 难度系数）
          + 主观题数 × 60（书写） + 客观题数 × 5（涂卡）
          + 阅读材料字数 × 0.2（读时）

题型基础秒数：选择题 45 / 判断题 30 / 填空题 60 / 多选题 70 / 阅读题 420 / 解答题 420
难度系数：易 ×0.8 / 中 ×1.0 / 难 ×1.3

建议时长 = 向上取整到 5 分钟（净分钟 × 1.05）
考试时间 = 向上取整到 5 分钟（净分钟 × 1.3），且不低于整卷模板的真实考试时长与「建议时长 + 10 分钟」
```

试卷面板实时显示「建议时长 / 考试时间」两项，Word / PDF 导出卷头同步使用；空卷时回退默认 45 / 90 分钟。

## 年级分档与难度校准（对标真实考情）

针对“九年级题太简单、难度区分度弱”的失真问题，按六个学段 × 三档难度重建了出题约束（调研自 2024 中考真题、组卷网难度系数、CMATH 小学基准等）：

| 学段 | 命题范围（对标真实考情） | 难度锚点 |
| --- | --- | --- |
| 1-2 年级（低） | 20 以内加减（凑十/破十）、表内乘除、简单两步应用 | 易=送分，中=两步，难=进位退位综合 |
| 3-4 年级（中） | 多位数乘除、长方形周长面积、单位换算、乘减混合应用 | 易=口算竖式，中=公式应用，难=两步综合 |
| 5-6 年级（高） | 分数/小数/百分数、比与比例、圆、圆柱体积、折扣问题 | 易=直接计算，中=公式变形，难=百分数/体积综合 |

- 难度锚点按「学段 × 三档」注入 AI 提示词（`ai.js → gradeBand`），生成链路把「年级 + 难度底线示例」传给模型，不再出现九年级出七年级题的情况。
- AI 提示词内置「年级与难度基准」并写明各年级“难”题底线（九年级=二次函数与几何综合/圆+相似、八年级=折叠+勾股/函数面积分类、七年级=数轴动点/含参方程等）；AI 返回后再加一轮**难度质检改写**——让模型逐题对照得分率锚点（易 >0.8 / 中 0.5—0.8 / 难 <0.35）自查，未达标的题当场改写到真正达标（质检失败自动保留原题，不影响出卷）。
- 命题页工具栏新增「难度锚点」提示，随年级/难度切换实时更新，让老师一眼看到当前档位。
- 语文/英语同样按学段分档：语文从笔画/句式 → 病句/默写 → 炼字赏析；英语从字母/单词 → 冠词/时态 → 宾语从句/被动/翻译（对标中考题型）。

## 学生端（比教师端更丰富的学习体验）

学生角色开放「知识点讲解库 / 错题本 / 学习计划」三大学习模块，比教师端更偏“把知识讲透”：

- **知识点讲解库**（`#/knowledge`，48 个知识点）：每个知识点按“一句话看懂 → 分步跟着做 → 例题演示 → 为什么这样想 → 记忆口诀 → 变式练习 → 易错点”七段展开，全部用贴近生活的语言把方法讲透，不做来源或版本上的区分，知识点就是知识点。内容覆盖三块：
  - **数学**（28 个）：课内数与运算、分数、方程、函数、几何全覆盖，另含竞赛/奥数专题（鸡兔同笼、抽屉原理、枚举与分类、奇偶性、极端思想、找规律、排列组合、同余周期、和差倍）与高数入门（极限、导数、积分思想、复合函数与反函数、指数与对数），高数部分用“无限接近 / 瞬时速度 / 切碎再求和”等大白话讲清概念，只作拓展不作拔高。
  - **语文**（10 个）：在课内阅读、病句基础上，新增学习方法（五遍读书法、批注精读、古诗文先懂再背、错题三本、考场阅读四步、作文素材卡、每日朗读、预习三读），方法经网络调研后用自己的话改写，直接可执行。
  - **英语**（10 个）：在自然拼读、语法基础上，新增学习方法（语块学习、主题单词本、间隔重复记忆、影子跟读、精听五步、滚动朗读、情景代入、词根词缀），方法同样经网络调研改写落地。
- **错题本**（`#/wrongbook`）：错题与计划配套习题合在一起，每题带“从知识点讲起的深度讲解 / 答案与详解 / 复习排期”，可标记“已掌握”；教师批改后错题自动进入，计划生成时配套习题自动写入。
- **学习计划**（`#/analytics/students/plan`）：学生可直接访问自己的 4 周提升计划，配套习题与每日投入安排（分钟 / 天、时段任务）同页展示并可打印；计划上方新增“计划 → 行动”任务区，完成后自动回写本地数据。
- **个性化推荐**：学生首页和知识点库顶部提供推荐流。排序依据公开可解释：错题 / 重点知识点 > 学科偏好 > 兴趣关键词 > 学习方式 > 推荐反馈；不感兴趣内容会从当前推荐中隐藏。
- 学生首页改为学习入口（知识点讲解 / 错题本 / 学习计划），导航与教师端隔离，教师端功能不受影响。

**连接方式与故障排查**：
- 「AI 设置」弹窗会显示当前连接方式：**云端中转**（部署 `server/` 后自动启用，由服务端转发模型请求，彻底绕开浏览器跨域限制）或**浏览器直连**。
- 在「AI 设置」填写的直连凭据（endpoint / 模型 / Key）在本地运行包中会**随中转请求一并转发**：即使 `server/.env` 未配置，管理员填写的 Key 也能真正连接模型；服务端未配置且中转不可用时，自动降级浏览器直连。
- 若直连报“无法连接 / Failed to fetch”：多半是浏览器跨域（CORS）拦截，优先部署 `server/` 用云端中转；其次换用支持跨域的免费服务商（硅基流动 / OpenRouter / Pollinations）。
- 报错会显示具体原因（接口状态码、超时、云端中转提示等）；模型接口返回 401/403 说明 Key 无效或未填，返回 402/404 说明接口地址或模型标识有误。
- 本地 Ollama 需先执行 `OLLAMA_ORIGINS=*` 再启动，否则浏览器直连会被拒。
- 云端 / 局域网服务若设置了 `FH_TOKEN`，请在账号菜单或学校管理中的「网络接入」填写，数据读写与 AI 中转请求才能通过鉴权。

**付费版大模型（旗舰）**：内置近两年主流旗舰模型库（OpenAI GPT-5 / GPT-4.1 / o3、Anthropic Claude Opus 4.1 / Sonnet 4.5、Google Gemini 2.5 Pro、DeepSeek-R1、Qwen3-Max、Kimi K2、GLM-4.6、豆包 Seed 1.6、MiniMax M2、Llama 4 等，共 21 款）。该模块**常规隐藏**，仅对「会员中心」中等级拉满（旗舰版）的用户开放；开通后通过用户自己的 OpenAI 兼容中转地址调用，可逐款测试连接。

**受众约束（面向偏远落后地区）**：出题、批改、生成详解、生成学习计划四条工作流统一注入“受众约束”——面向偏远落后地区义务教育阶段的学生、教师和家长，语言必须平实通俗、禁止只甩专业术语（必要时紧跟一句大白话解释），建议具体到每天 / 每次怎么练，像耐心的乡村教师一样先讲概念、再用生活例子、最后给可执行做法。

配置后：

- 命题组卷「AI 生成」改为调用免费模型，按学科 / 年级 / 教材版本与勾选知识点、题型、难度生成题目与详解（要求返回 JSON）；每批仅 2-3 题，逐题校验难度与字段，缺漏自动用同难度本地题补全，数量与难度不缩水。
- 整卷模板同样走分块生成：每个大题（选择/填空/解答）独立按难度分布生成，避免一次性请求过多导致返回不全。

- 「学习计划书」：结合长期作业数据生成下一阶段个性化计划。
- 所有调用均带超时与明确报错：未配置、断网或接口失败时**不会**回退到本地示例，而是提示“请先接入 AI 模型”或给出具体失败原因（接口状态码 / 超时 / 跨域建议）；顶栏状态徽标实时显示当前 AI 来源。

## 手机 / 平板适配

- **平板（≤1024px）**：顶栏全局导航隐藏（侧边栏承担导航）；命题页三栏改为单列纵向布局，知识点树可一键「收起 / 展开」，试卷面板回到正常文档流；表格保留容器内横向滚动。
- **手机（≤640px）**：
  - 顶栏精简为图标 + 品牌，账号只显示头像；通知 / 账号下拉改为屏幕宽度内的抽屉菜单。
  - 侧边栏变为底部弹层式抽屉（82vw 宽），带遮罩，点遮罩或切换页面自动收起。
  - 命题页：工具栏纵向排布、生成按钮全宽；知识点树默认可折叠；右下角悬浮「试卷」按钮一键跳到试卷面板；题目卡片操作按钮两列排列。
  - 表格在容器内横向滚动（`.table-wrap`），不会撑破页面；弹窗改为底部弹层（圆角上滑），Toast 横贯屏幕底部。
  - 登录页、筛选栏、阅读检索栏、图表（SVG / Chart.js）均按屏宽自适应，图形随卡片缩放。
  - 双栏内联布局（贡献资料、导出报告、学生明细、计划配套等）统一走 `.grid-2`，手机端自动折为单列；卡片/网格子项加 `min-width:0`，长标题自动换行，页面级横向溢出清零。
- 适配不改变既有功能：在 360 / 390 / 414（手机）、768 / 1024（平板）、1440（桌面）多档宽度下全部路由无页面级横向溢出（表格仅在容器内横向滚动），交互回归全部通过；手机无需旋转到平板比例使用。
